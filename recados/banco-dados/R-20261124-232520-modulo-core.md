# GRANT INSERT em core.empresa para macuxierp_worker (consumidor da RN-CORE-14)

## Contexto
Contexto: o consumidor core.empresa-da-filial-padrao (docs/desenho/T-0100.md §3) roda no worker e faz INSERT INTO core.empresa ... ON CONFLICT (tenant_id) DO NOTHING; a 0003 só dá SELECT em core.empresa ao macuxierp_worker (INSERT só ao macuxierp_app), então o teste de banco no papel worker falha com permission denied for table empresa. Mesmo precedente da 0029_estoque_worker.

## O que preciso / o que mudou
O que preciso: migração nova com GRANT INSERT ON core.empresa TO macuxierp_worker (só INSERT, sem UPDATE nem DELETE; o INSERT com ON CONFLICT exige também o SELECT que já existe), com teste de privilégio.

## Pronto quando
Pronto quando: a migração está no main e o teste modules/core/api/consumidor-empresa-da-filial.db.test.ts passa sem GRANT local.
