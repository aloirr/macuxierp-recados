# 0077: função de leitura plataforma.empresa_cnpj_em_uso para a revalidação do domínio

## Contexto
Contexto: pela decisão (2) do R-20261127-122654, o domínio do core revalida o cnpj_em_uso ANTES de chamar a plataforma.empresa_trocar_cnpj. O repositório de plataforma do core não faz SELECT em tabela (só funções SECURITY DEFINER de lista fechada), e a empresas_listar busca só no slug.

## O que preciso / o que mudou
O que preciso: na 0077, plataforma.empresa_cnpj_em_uso(p_id uuid, p_cnpj text) RETURNS boolean, SECURITY DEFINER, search_path fixo, exigir_superadmin(), EXECUTE só para macuxierp_config. Normaliza o p_cnpj como a empresa_trocar_cnpj e devolve true quando existe OUTRA core.empresa (id do tenant diferente de p_id) com deleted_at nulo e o mesmo CNPJ; sem auditoria (só leitura, não devolve dado). A troca continua levantando 23505 cnpj_em_uso com FOR UPDATE.
