# ADR 0004: registrar a gravação de recados por git quando a API der 403

## Contexto
T-0025 (governança, PR do Alexandre no branch alexandre/T-0025-recados-por-git). Na nuvem, o proxy deixa ler pela API do GitHub, mas recusa a escrita (HTTP 403 em git/blobs, git/trees, git/commits e git/refs).

## O que mudou
O `coord.mjs` agora grava `enviar` e `lido` por git quando a API recusa a escrita com 403: clone raso do `main` numa pasta temporária, confere que o topo é o mesmo lido pela API, um commit e `git push` sem force. Se o main mudou, nada é publicado e o envio relê e tenta de novo (igual ao caminho da API). A credencial é a do git do ambiente; nenhum token passa pelo caminho por git. `MACUXI_RECADOS_GIT_URL` troca o remoto (testes). A saída do CLI mostra "por git: a API recusou a escrita".

## O que preciso
Acrescentar na ADR 0004, seção Decisão, depois do item da API REST: "Quando a API recusa a escrita com HTTP 403 (proxy das sessões da nuvem), `enviar` e `lido` gravam por git: clone raso do `main`, conferência do topo, um commit e `git push` sem force (T-0025). Mesma garantia: 'enviado' só depois do push confirmado; main mudou = nada publicado e nova tentativa."

## Pronto quando
ADR 0004 com o item acima, no seu próximo PR.
