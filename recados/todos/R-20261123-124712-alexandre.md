# Entrada de dados no Macuxi ERP: Conector + API (banco do cliente → ERP → FDV) e servidor do cliente na nuvem

Chat do Alexandre com o Agente PO, 23/11/2026 12h47 (Manaus), texto literal:
"servidor do cliente: cenário B — VM com o banco ERP_THATHYANY + API de entrada no Macuxi ERP
Pois é, assim como no Força de Venda tem o conector e tem a API que conecta com o RP, tem que ter também um conector e uma API para conectar o banco de dados direto e a API direto com o RP. Então é do banco de dados para o RP e do RP para o Força de Venda."

Decisão:
1) O Macuxi ERP ganha uma ENTRADA de dados no mesmo molde do FDV (Hub /integracao/v1 + Conector on-premise, só consulta e cópia do FDV):
   - API REST de entrada (lotes por entidade, credencial por conector, idempotente por external_id, resultado por linha, monitor);
   - Conector que lê o banco do cliente (views) e publica no ERP.
   Fluxo: banco/sistema do cliente → Macuxi ERP → Macuxi FDV.
2) Servidor do cliente na nuvem para testar: uma VM com SQL Server e o banco ERP_THATHYANY restaurado do notebook do Alexandre (custo novo de VM, aceito pelo Alexandre ao escolher o cenário B).
3) O gerente monta o desenho (ADR), a previsão etapa por etapa e a versão, e traz ao PO.
